Comparing consecutive projections gave exactly the 19 field edits in [changes.tsv](changes.tsv) across five transitions; 37 transitions changed no logged setting. The inventory owner also matched the final run-level config to E, not A. The SHA-256 of the archived final YAML is `a414698836a80109999ea50513a3b3fa3d1641bed859c93597839b09bf4610d9` (owner check); string serialization and hash scope differ from the dictionary signatures above.

**How to read the files.** These are settings records, not importable launch configurations. Strings such as `"True"` and `"2"`, list order, nulls, and missing fields are retained as logged. In particular, the resolved optimizer and schedule override their defaults selectors. Object-store location/credential fields, job namespace and cluster fields, the upload flag (false), and empty recorder metadata are omitted. Type/target strings identify implementation symbols without private import paths; resolve each against the pinned historical code, not a similarly named modern class. Checkpoint and backbone locations are represented by role. The checkpoint mount token is **not** a checkpoint identifier. Retain the original trainer and loader state on a full resume; do not treat `load_training_state` or `keys_not_to_resume` in a startup config as evidence of what an owned-checkpoint restore loaded.

All 15 ordered family root lists were compared with the public `cosmos3_h_embodied/configs/openh_datasets.py` at `14d1626`: 55/55 mapped per start, including entries the public loader normally omits. The clean-stream requirement maps to the same wound-closure root. The valid-window sidecar and exclusion overlay are named, not included. Look up actual root versions in the private release data inventory: equal logical names do **not** mean equal directories. In particular use the **older** Stanford peg-transfer copy in this stage, not the later row-index repair. Do not replace XYZW or the idle-frame caption behavior with the H16 defaults.
