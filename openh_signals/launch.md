# Per-worker attachment (v1)

Invoke **the original worker's Python**, not the outer process supervisor. `launch.py` is a Python script so the disabled path does not import this package (even `__init__`), and it execs the original interpreter with the original script/module arguments:

```
python <observer>/openh_signals/launch.py -m <worker> [worker arguments]
python <observer>/openh_signals/launch.py --internal-signals <private-manifest> -- -m <worker> [worker arguments]
```

A script path in place of `-m <worker>` is also accepted. Do not use `python -m openh_signals.launch` to test the disabled-import contract. The worker entrypoint and training code are not edited. No Python module or code from the manifest is executed. The manifest binds the protocol, plan SHA256, source commit, resolved-config digest, private probe-list path + SHA256, private run directory, reserved/previously-charged/unique-kept bytes. It is not a data gate or a substitute for the owner's physical binding.

## Current support versus release qualifications

- `Runtime.install(commit)` checks the loaded hook sites against tracked bytes at the exact supported revision. It wraps the selected native or framework two-way call, network, per-layer attention, Wan encoder/decoder, and solver. Contexts restore original functions on exceptions. `Runtime.cell(metadata)` scopes diagnostic observations independently of forward/backward replay; natural training does not emit attention panels.
- `TrainSteps.install(commit)` binds the **trainer's** actual `training_step`, pre-optimizer callback, model noise inputs, and native objective binding. It stages per-microstep records, joins scaled-gradient hooks, and emits only on a completed accumulation with one observed optimizer step. It refuses unsupported fused optimizers, unknown layouts, and skipped/misnumbered updates. Fixed-noise probes must be independently scheduled on the corresponding isolated snapshot by a qualified coordinator; a `training_step` callback must never re-run training inputs. The stage-2 entry is not an optimizer update.
- `EvalCalls.install(commit)` binds `generate_batch`, `UniPCSampler.forward` (via `Runtime.install`) and `_get_velocity`. It needs a protocol-specific function validating the actual physical target digest, seed, solver, branch and clip rather than trusting an evaluator ordinal. A missing solver call, unknown branch or unsupported fused layout is an error. Cached text never synthesizes a missing query. Attach the scorer to the actual evaluator binding before its module imports `compute_sample_metrics`; do not patch an unrelated alias.
- `label_pack` covers the verified ordinary one-camera, one-transition-sequence-per-sample layout only, including short history and optional three memory rows. Per-sample lengths, sorted complete disjoint physical indices, actual geometry, and two-way splits are checked. Supply text classes keyed by the SHA-256 of the actual packed token IDs (signed little-endian int64, including boundaries), derived using upstream tokenizer offsets. Missing/ambiguous assignments hold the worker.
- `SingleWorkerEvaluation` binds the public scorer **script** by blob, wraps its actual return rather than scoring a second time, and checks actual in-memory video+action bytes/dtypes/shapes versus the private physical-window catalog before collecting a clip. The catalog supplies `instances`, not just a list of evaluator ordinals: name, family, seed, mode, chunk, ablation, held-out/root/index/target/window digests, branch token digests, expected solver branches, required signals, probe/sentinel flags. The scorer must return a matching future-action digest when present. Every selected branch must report all 36 layers. The coordinator reduces homologous fields to equal-clip stratum means with finite counts, saves complete records for fixed probes, small diagnostics for all scored instances and a separate full-map tier. It publishes only after every declared instance was scored. Mismatched identities, protocol counts, budgets and unsupported topologies raise errors. `tests/signals/test_runtime_store.py` exercises the collector with synthetic cells, not a scored pass. The synchronous process does not claim to implement cross-worker reduction, replay, a frozen producer-side join, or the production fixed-noise probe player.
- Launch qualification is code-owned and specific to the exact whole manifest (including worker-argument hash, source, private probe digest, config and capacity). **No production worker is registered at this revision.** The general launch gate checks for an implemented, qualified preflight+coordinator binding; it does not turn a successful leaf test or a boolean in a JSON into a production authorization. Unsupported shard attribution, trainer/replay/backend behavior, unresolved root/probe mapping, snapshot isolation, or missing signal families block a release.

## Reproduce the launch check (synthetic, CPU)

```
python -m pytest -q tests/signals/test_runtime.py
```

The launch test writes a private manifest and empty synthetic text-span catalog in a temp directory (`protocol=wan-cpu-calibration`); the deliberately small worker instantiates the pinned `Encoder3d` from randomly initialized weights, not a trainer. It receives **no observer API arguments**. The test compares its two forward/backward/update steps and verifies the enabled launcher's private signal file, actual `encoder.spatial` records at both time planes, and absence of observer imports/files when disabled. The catalog is a launch input, not a probe list in git. Do not add data, private probe IDs or example output files to this branch.
